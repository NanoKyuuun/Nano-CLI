# NanoCLI

Local AI Coding Assistant berbasis CLI dengan Project Memory.

## Fitur Utama
- **Ask**: Tanya cepat dari terminal.
- **Chat**: Sesi interaktif dengan AI.
- **Review**: Audit kode per file.
- **Debug**: Analisis error dan solusi.
- **Memory**: Pemahaman konteks proyek secara berkelanjutan.

## Instalasi
```bash
pip install -e .
```

## Penggunaan
```bash
nanocli --help
```
